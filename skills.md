# Frontend Design Skill

Cuando diseñes una interfaz web, sigue estas reglas:

## Diseño general

- Crear interfaces modernas y profesionales.
- Evitar diseños que parezcan plantillas genéricas de IA.
- Priorizar una apariencia limpia y visualmente atractiva.
- Mantener una jerarquía visual clara.
- Usar correctamente espacios en blanco.
- No saturar la pantalla con demasiados elementos.

## Tipografía

- Usar tamaños de texto claramente diferenciados.
- Los títulos deben destacar.
- Mantener buena legibilidad.
- Usar un máximo de 2 familias tipográficas.

## Colores

- Elegir una paleta coherente.
- Usar un color principal y colores secundarios.
- Mantener buen contraste.
- No utilizar demasiados colores diferentes.

## Componentes

- Crear botones modernos con estados hover.
- Usar bordes redondeados de manera consistente.
- Crear tarjetas visualmente atractivas.
- Añadir sombras sutiles.
- Mantener espaciados consistentes.

## Responsive Design

Antes de terminar, verificar:

1. Diseño para escritorio.
2. Diseño para tablet.
3. Diseño para móvil.
4. Que no exista scroll horizontal innecesario.
5. Que botones y elementos sean fáciles de usar en móvil.

## UX

Antes de implementar una página:

1. Analizar cuál es el objetivo principal.
2. Identificar qué información debe llamar primero la atención.
3. Crear una jerarquía visual.
4. Reducir elementos innecesarios.
5. Priorizar una experiencia simple e intuitiva.

## Calidad visual

Antes de finalizar:

- Revisar que todos los márgenes sean consistentes.
- Revisar alineaciones.
- Revisar tamaños de botones.
- Revisar colores.
- Revisar la versión móvil.
- Mejorar cualquier sección que se vea vacía, genérica o poco profesional.

No conformarse con una implementación funcional.
La interfaz debe sentirse como un producto moderno y terminado.

## Evitar apariencia generada por IA

No utilizar automáticamente tendencias visuales populares sin evaluar
si son apropiadas para el proyecto.

Evitar:

- Gradientes innecesarios.
- Fondos con grids, puntos o partículas decorativas.
- Efectos neon o glow excesivos.
- Dashboards falsos solamente como decoración.
- Demasiadas tarjetas flotantes.
- Bordes extremadamente redondeados en todos los elementos.
- Badges y pills innecesarios.
- Títulos excesivamente grandes.
- Diseños genéricos estilo SaaS.
- Elementos visuales que no aporten funcionalidad.

Preferir:

- Tipografía bien trabajada.
- Espaciado consistente.
- Layouts simples.
- Jerarquía visual clara.
- Componentes con propósito.
- Detalles visuales sutiles.
- Diseños inspirados en productos reales.
- Variación visual entre secciones.
- Interfaces que parezcan diseñadas para el problema específico
  del proyecto y no reutilizadas de una plantilla genérica.

Antes de implementar un diseño, preguntarse:

"¿Este elemento existe porque mejora la experiencia del usuario
o simplemente porque se ve moderno?"

Si no mejora la experiencia, eliminarlo.
